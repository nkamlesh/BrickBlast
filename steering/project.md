# BrickBlast — Project Overview

## What This Project Is
BrickBlast is a browser-based brick-breaking game built with vanilla HTML, CSS, 
and JavaScript. No frameworks, no build tools, no dependencies. The player 
controls a paddle to bounce a ball and destroy bricks, earning points for each 
brick destroyed.

## Project Goals
- Create a fully playable game that runs directly in a browser
- Keep the code simple, readable, and well-commented
- Demonstrate clean vanilla JavaScript game development patterns
- The game should work by simply opening index.html in a browser

## Target Audience
This is a learning/demo project. Code clarity is more important than 
performance optimisation.
